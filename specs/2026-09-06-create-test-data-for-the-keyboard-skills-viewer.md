# Create Test Data For The Keyboard Skills Viewer

## Scope

This is a simple JavaScript programme that tests a child's reading, writing and keyboard skills. It displays a word to the user; if the word is typed correctly, it reveals an image as a reward, then advances to the next word. Words and images are defined in simple JSON files containing objects with `word:` and `image:` fields, where `image:` points to a URL on the internet.

For this iteration, we are only creating test data: a JSON file at `assets/data/test.json` containing test entries for a ball, a car, and an elephant. The images will be sourced from Wikimedia Commons.
