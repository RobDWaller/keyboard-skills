# Display First Word And Image

## Scope

Building on the test data created in the previous iteration, this phase creates the initial HTML and JavaScript for the Keyboard Skills Viewer. The system will consist of:

- An `index.html` page in the project root that serves as the entry point
- A JavaScript file at `assets/js/main.js` containing the application logic

For this iteration, the application will load `assets/data/test.json` and display only the first word and its corresponding image on the page. No interactivity or keyboard input handling is required yet.

## Build Plan

**For each step in the build plan commit the code before completing the next step.**

### Step 1
Create the `assets/js/` directory structure.

### Step 2
Create `index.html` in the project root with basic HTML structure and a script link to `assets/js/main.js`.

### Step 3
Create `assets/js/main.js` that fetches `assets/data/test.json`, extracts the first word and image, and renders them to the DOM.

### Step 4
Commit the HTML and JavaScript files.
